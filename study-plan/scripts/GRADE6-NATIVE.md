## 契约与安全

- 公开数据仅 `{id, inputs, native}`，文字/公式/原位输入/表格/SVG 白名单形状；没有 HTML、图片节点、外链、事件或参考答案字段。
- 每个输入字段恰好在题干或相应小题后出现一次；多空不能合并为逗号分隔的单框。
- 作图为独立 `drawing` 字段；学生图形是严格 JSON，不能提交 SVG/HTML 代码。图元、坐标、画板、长度均有上限；作图仍需审核，不冒充系统自动判对。
- 旧综合作答只读显示，不猜测拆分，不在读取时写入数据。显式重新作答才按新字段保存；题目 ID 不变，旧已答统计保留。
- 新版请求必须包含精确的公开输入结构 `input_schema` 标记，缺少或过期标记的旧页面不能写回旧聚合作答。该标记不是凭据；仍需家庭访问、同源校验与修订号保护。本地草稿另带结构版本，完整保留未提交多空。
- 答案只由服务端读加密包，提交成功并确认版本后才返回反馈。保留并发修订保护。
- Git 将题库 JSON 固定为 LF 换行，Windows/Linux 拉取后的摘要一致，避免字节级配套验证因自动换行转换而失败。
- 已核对原生题的数值判题使用有界 BigInt 有理数精确比较；接受等值分数、小数、百分数和带分数，不使用相对浮点容差，以免把较大数值的错误末位判对。原题要求近似值时按明确精度核对，不猜四舍五入。
- 教师版可能有笔误、漏题或跨页答案。不能直接把教师裁图的示例当唯一解；须回查完整原卷/教师页，独立复算，保留更正依据。无法确认的题保持未审阅，阻止整库上线。

在 `study-plan` 工作目录执行：

```powershell
node scripts/test-grade6-bank-native.mjs

node scripts/test-grade6-bank.mjs

```

最后一条只往项目根 `tmp/grade6-bank-native/` 写无答案预览和状态。当前 `converted=reviewed=2394`、`pending=0`、`releaseReady=true`。任一作者批次、源题或教师材料变动使摘要失效时，以非零退出并阻止发布。不得为了通过而把候选题标为已核对。

所有 `--attest-reviewed-*` 门槛只允许对应的已独立复核批次固定摘要、数量和稳定题号范围，不会给未来新增或改动题自动盖章。新批次必须独立逐题比较原文、所有小题/空/单位/公式/图形及教师答案，建立新的审阅记录。

`audit-grade6-bank-native-coverage.mjs` 可复用本地几何缓存生成全库审计；`draft-grade6-bank-native.py` 仅生成不含答案的未审核候选。候选有分数位置、页脚、多结果空等保守拦截，永远不计为已转换/验证，不允许拿候选作为发布包。

`prepare-grade6-native-ui-preview.mjs` 仅把公开审核数据和实际渲染组件复制到 `../tmp/native-bank-preview`；预览使用独立内存进度 hook，无真实判题密钥、家庭访问、学生数据库或网络写入。通过 `?collection=chapter-0` / `?collection=chapter-1` 检查各章原题号；预览不得冒充上线验收。

`node scripts/build-grade6-bank-native.mjs --seal` 仅在 2,394 个原 ID 全覆盖、所有作者数据合格且审阅摘要有效时生成完整公开包与加密答案包；使用既有判题密钥，密钥只保留在内存。它不调用部署、网络或学生数据库。
